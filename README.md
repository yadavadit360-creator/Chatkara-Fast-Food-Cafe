## 🚀 Getting Started

### Option 1: View Locally
1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! The website is ready to use

### Option 2: Deploy Online

**Using GitHub Pages:**
1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose "main" branch and "/root" folder
4. Your site will be live at: `https://yadavadit360-creator.github.io/Chatkara-Fast-Food-Cafe/`

**Using Netlify (Recommended):**
1. Sign up at [netlify.com](https://netlify.com)
2. Drag and drop the folder or connect your GitHub repo
3. Your site will be live in seconds!

**Using Vercel:**
1. Sign up at [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Deploy automatically

## ✏️ Customization

### Update Restaurant Information
Edit these sections in `index.html`:

```html
<!-- Location -->
<p>123 Food Street, Main Market<br>Your City, State 12345</p>

<!-- Phone -->
<p>+91 98765 43210<br>+91 98765 43211</p>

<!-- Email -->
<p>hello@chatkara.com<br>orders@chatkara.com</p>

<!-- Hours -->
<p>Mon - Sun: 10:00 AM - 11:00 PM<br>Holidays: 12:00 PM - 10:00 PM</p>
```

### Update Colors
Edit these in `styles.css`:

```css
:root {
    --primary-color: #FF6B35;      /* Orange - main color */
    --secondary-color: #F7931E;    /* Yellow - secondary */
    --dark-color: #1a1a1a;         /* Dark text */
    --light-color: #f4f4f4;        /* Light background */
}
```

### Add Your Logo
Replace the text logo with an image in `index.html`:

```html
<div class="logo">
    <img src="logo.png" alt="Chatkara Logo" height="40">
    Chatkara
</div>
```

### Update Menu Items
Edit menu items in the Menu Grid section of `index.html` with your own items and prices.

### Add Social Media Links
Update social links in footer with your profiles:

```html
<a href="https://facebook.com/chatkara"><i class="fab fa-facebook"></i></a>
<a href="https://instagram.com/chatkara"><i class="fab fa-instagram"></i></a>
```
